Skill、知识库、工具与权限矩阵

Skill 教模型“怎样做”；知识库提供“依据什么做”；工具决定“能实际做什么”。三者分离配置。

Skill 渐进加载

先加载名称与适用场景，命中任务后再加载完整操作步骤，最后按需读取模板、脚本和参考资料。

三层知识库

平台权威资料 → 公司私有资料 → 当前任务附件。法务、财务、人事默认禁止跨部门检索。

最小工具权限

只读工具可自动执行；内部写入留版本；外发、发布、付款、合同定稿、生产变更必须人工批准。

选型原则：文档、PDF、表格、演示文稿采用成熟 Agent Skills 结构；财务建模参考公开金融服务 Skill，但改造成经营财务与内控版本；法务、HR、营销及中国平台规则不直接安装来源不明的社区 Skill，而是用官方法规、公司制度和真实流程构建并做任务级评测。

图片上传

支持 PNG、JPG/JPEG、WEBP。先做文件签名与大小校验，再进行 OCR、版面理解和多模态分析；保存原图、提取文本、页块坐标和来源关系。

文件上传

首版支持 PDF、DOCX、XLSX、PPTX、TXT、MD、CSV。执行恶意文件检查、格式解析、敏感信息识别、部门权限判断；默认只进入任务临时区，用户明确选择后才沉淀到公司或部门知识库。
