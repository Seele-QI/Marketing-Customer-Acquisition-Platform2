# 招财猫 · 从安装到出片检查清单

> 一页速查。给已装用户 / 试用用户的「更新 + 出片」自助卡。
> 微信发送前可先请对方留个邮箱，作为邮件列表的交换物。

---

## A. 我要不要重下安装包？（大多数情况：不用）

| 你的情况 | 该怎么做 |
|----------|----------|
| 已经装过招财猫 | **不用重下**。打开 **设置 → 应用更新 → 检查更新**，下载完成后重启即可 |
| 从没装过 | 用最新 `招财猫-Setup-x.y.z.exe` 安装一次 |
| 点了检查更新但失败 | 见下方 D「更新失败自助」，仍不行再用完整 Setup 安装 |

一句话：**云端在北京节点，桌面平时不用重装；更新像微信一样点一下就好。**

---

## B. 三步完成更新

1. 左下角 **设置** → **应用更新**
2. 点 **检查更新**（会显示当前版本 / 最新版本 / 更新说明）
3. 下载进度跑完 → 点 **立即重启并安装**

> 首次或差分对不上时会自动拉完整包，属正常，等进度条即可。

---

## C. 首次出片 30 秒清单

1. 登录（邮箱验证码）→ 确认右上角积分余额
2. 选模块：**数字人口播** / **图文视频** / **视频混剪** / **文案**
3. 备好素材：口播文案 + 音色样本（或图片/视频素材）
4. 提交后**不要关窗**，进度条按阶段推进；完成后下载 `.mp4`
5. 首次建议先跑一条短的，跑通再上量

---

## D. 更新失败自助（3 条先自查）

1. **网络**：能否打开任意网页；公司网/校园网可能拦截下载
2. **重试**：关掉招财猫重开，再 **设置 → 检查更新**
3. **兜底**：仍失败就用最新完整 `Setup.exe` 覆盖安装，数据和积分不受影响

> 如果提示 Windows「未知发布者」：点 **更多信息 → 仍要运行** 即可。
