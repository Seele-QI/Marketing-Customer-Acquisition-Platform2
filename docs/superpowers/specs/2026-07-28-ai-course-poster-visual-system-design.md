# AI 课程总纲海报视觉系统设计

## 1. 目标

为《AI超级个体与企业提效实战营》建立一套可持续扩展的高端课程品牌海报系统。首批交付“课程总纲”三版，用户确认后再扩展“双价值体系总纲”和“能力升级总纲”，最终形成 3 类内容 × 3 版构图。

## 2. 已确认的参考方向

用户提供的 7 张参考图共同定义了本项目的视觉边界：

- 黑色、石墨灰为主体，香槟铜金为强调色，白色用于正文。
- 中文宋体或高对比标题字体配合克制的无衬线正文。
- 大面积留黑、细线分区、严格对齐，信息密集但不拥挤。
- 使用岩石、山体、金属裂隙、未来建筑等真实材质主视觉。
- 采用品牌画册和课程长图逻辑，不采用短视频促销大字报逻辑。
- 不出现人物、头像、背影、手部、机器人或拟人 AI。
- 不使用网页卡片、毛玻璃、霓虹、促销笔刷、印章、价格条或廉价 3D 字。

参考图片的外层灰色“案例分享”展示板不属于成品风格。最终交付仅包含内部黑色课程长海报。

## 3. 输出规格

- 母版比例：9:16 竖版长海报。
- 工作尺寸：1440 × 2560 px。
- 文件格式：PNG。
- 输出目录：`docs/tutorial-assets/course-system/premium-posters/`。
- 首批文件：
  - `course-overview-a-obsidian-mountain.png`
  - `course-overview-b-golden-architecture.png`
  - `course-overview-c-bronze-data-core.png`

## 5. 课程总纲信息结构

海报文字采用本地确定性排版，不让生成模型直接绘制大段中文。

### 顶部品牌区

- 英文眉题：`AI BUSINESS OPERATING SYSTEM`
- 主标题：`AI超级个体与企业提效实战营`
- 副标题：`一个人的AI团队，一家企业的提效系统`
- 课程规模：`20 LESSONS · 30–60 MIN`

### 核心价值区

- 创业者：`一个人使用AI，创造过去一个团队的价值`
- 企业：`员工提高单人产出，组织实现降本增效`

### 四阶段课程结构

1. `01–08 通用工具基础`
   - 任务分配、定位、知识库、内容、图片、视频、GEO
2. `09–13 一人公司创业`
   - 方向验证、产品设计、内容获客、抖音截流、项目交付
3. `14–18 企业降本增效`
   - 岗位提效、知识沉淀、内容生产线、获客系统、智能体团队
4. `19–20 综合落地`
   - AI团队搭建、30天行动方案

### 工具体系区

- 核心：`AI中台`
- 获客：`抖音截流`
- 办公：`WorkBuddy`
- 补充：`通用大模型与专业工具`

### 底部能力链

`定位 → 生产 → 传播 → 获客 → 交付 → 复盘`

## 6. 制作方法

1. 使用 imagegen，分别以用户参考图作为视觉参考，生成三张无文字或极少文字的原创主视觉底图。
2. 使用本地位图排版脚本叠加全部中文和英文，确保文字准确、字体统一、字号可控。
3. 使用本地字体：
   - 中文标题优先思源宋体、方正宋体或系统宋体。
   - 中文正文优先思源黑体、微软雅黑。
   - 英文标题使用高对比衬线体，英文信息使用窄体无衬线体。
4. 输出后检查：
   - 1440 × 2560；
   - 无人物；
   - 中文无错字；
   - 四阶段信息完整；
   - 工具名称准确；
   - 缩略图状态下仍能辨认主标题和核心价值。

## 7. 验收边界

- 三张图必须属于同一品牌体系，但主视觉构图明显不同。
- 不复刻参考图中的品牌、Logo、课程名、讲师、价格或原始素材。
- 主视觉可由生成模型完成，课程文字必须由本地排版完成。
- 本轮只完成课程总纲三版；后两类总纲在用户选择或确认方向后继续。
