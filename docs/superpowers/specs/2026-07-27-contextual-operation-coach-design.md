# 视频与 GEO 页面操作教练设计

日期：2026-07-27  
状态：待用户确认  
方案：A — 确定性页面指导优先，AI 问答辅助

## 1. 目标

把现有“创建项目后才能使用”的业务助理改造成真正悬浮在程序中的页面操作教练。

用户进入任意视频创作或 GEO 页面后，无需创建项目、无需先发消息，打开悬浮框即可知道：

1. 当前页面解决什么问题；
2. 自己正处于哪一个业务步骤；
3. 现在应该填写、上传或选择什么；
4. 完成当前步骤的判断标准；
5. 下一步应该点击哪个真实控件；
6. 遇到错误时如何排查。

项目规划、长期记忆和 AI 对话继续保留，但不得成为页面指导的前置条件。

## 2. 产品边界

### 启用范围

- 视频创作助理：
  - 数字人口播视频（新）
  - 数字人视频创作（经济版）
  - 图文视频
  - 视频混剪
  - 宣传视频
  - 视频历史记录
- GEO 助理：
  - 企业知识库搭建
  - 内容矩阵规划
  - 深度优化文章创作

### 不启用范围

- 身份定位不注册专属助理。
- 海报图创作不注册专属助理。
- 抖音截流助理只预留，不提供入口和指导内容。
- 工作台只显示视频/GEO业务入口和助理入口，不虚构其他助理。

当用户从视频/GEO切换到不支持的页面时，已打开的悬浮框可以保留，但明确显示“当前页面暂无专属指导”，并提供返回原业务页面的按钮，不冒充当前页面助理。

## 3. 核心交互

### 3.1 收起状态

右下角保留悬浮入口，内容随当前页面变化：

- 视频页面：`视频操作教练`
- GEO 页面：`GEO 操作教练`
- 不支持页面且没有已选项目：`创作指南`
- 不支持页面但存在已选项目：显示原项目助理名称，同时标记“当前页面外”

悬浮入口只负责打开面板，不自动创建项目、不发起接口请求、不扣积分。

### 3.2 默认展开状态

面板默认进入“操作指南”，不是“项目创建”或空对话。

顶部显示：

- 当前模块与页面名称；
- 当前业务步骤，例如“第 1 步：上传企业资料”；
- 当前完成度，例如“已完成 1/4”；
- 页面切换后自动更新。

主体按固定优先级显示：

1. `这一页做什么`
2. `现在需要准备`
3. `按这个顺序操作`
4. `完成标准`
5. `常见问题`

底部主按钮：

- `定位到当前操作`
- `下一步`
- 最后一步显示 `完成本页指导`

### 3.3 真实控件定位

指导步骤可以绑定一个 `data-tutorial-id`。

点击“定位到当前操作”时：

1. 查找当前页面对应元素；
2. 自动滚动到可视区域；
3. 使用高亮光圈标出目标；
4. 保持页面可操作，不用全屏遮罩阻断用户；
5. 目标不存在时在面板内提示“页面结构已变化，请按文字说明操作”，不得抛出运行时异常。

高亮只负责引导，不代替点击、上传、生成、扣费或发布。

### 3.4 步骤推进

步骤推进分为两类：

- 可观察步骤：根据当前页面状态自动识别完成，例如已上传素材、已有脚本、任务已进入运行态。
- 不可观察步骤：由用户点击“我已完成”推进。

教练不得因为用户点击“下一步”就声称真实业务已经完成。真实完成状态仍以草稿、运行任务终态、生成结果或 GEO 评分为证据。

### 3.5 AI 问答

“问助理”作为二级能力，不占用默认首页。

发给模型的上下文只包含：

- 当前业务模块；
- 当前页面；
- 当前指导步骤；
- 当前页面允许公开的状态摘要；
- 项目目标与计划（如果项目存在）；
- 视频或 GEO 对应专业记忆。

AI 主要回答：

- 这个字段怎么填写；
- 上传什么素材更合适；
- 为什么无法进入下一步；
- 当前结果如何优化；
- 下一步应该做什么。

AI 返回的动作只允许定位控件、切换合法业务页面和建议计划。生成、扣费、发布、删除、外部触达仍需用户在真实业务页面确认。

## 4. 信息架构

面板采用三个一级标签：

### 操作指南

默认标签。无项目也可以使用，展示当前页面的确定性指导。

### 问助理

结合当前指导步骤的业务问答。没有项目时仍能问“当前页面怎么用”；需要长期计划时才提示创建项目。

### 我的进度

包含：

- 当前页面指导完成度；
- 已选择项目的阶段计划；
- 最近任务运行状态；
- 业务记忆是否已接入。

没有项目时显示“当前使用进度仅保存在本机”，并提供非阻断的“建立长期项目”入口。

原来的“对话 / 计划 / 记忆”不会丢失，而是分别合并到“问助理 / 我的进度”，减少理解成本。

## 5. 指导数据模型

新增纯前端页面指导注册表：

```ts
type OperationGuide = {
  assistantId: "video-creation" | "geo-growth"
  view: string
  title: string
  purpose: string
  preparation: string[]
  steps: OperationGuideStep[]
  commonIssues: Array<{ problem: string; solution: string }>
}

type OperationGuideStep = {
  id: string
  title: string
  instruction: string
  completionCriteria: string
  highlightTarget?: string
  linkedView?: string
  completionProbe?: "manual" | "runtime-running" | "runtime-success"
}
```

注册表优先复用 `lib/tutorial/scenarios.ts` 中已经验证的业务说明、计费提示、输入输出和流程顺序。悬浮教练只增加更细的控件锚点与完成标准，不再维护一套含义相反的教程。

## 6. 页面上下文

`BusinessAssistantProvider` 统一发布：

- `activeView`
- `assistantId`
- `guideId`
- `guideStepId`
- `runtimeTaskId`
- `runtimeStatus`
- `runtimeProgress`
- `stageLabel`
- 允许公开的页面状态摘要

页面组件不得把完整表单、上传文件内容、密钥、Cookie、Token或原始附件传给悬浮框。

视频运行任务从现有 `task-runtime` 读取。GEO向导步骤由各工作区根组件发布简短状态，不把整个组件状态提升到全局。

## 7. 项目与接口降级

页面指导完全独立于 `/api/business-assistant/projects`。

项目接口的调用时机调整为：

- 面板打开时不创建项目；
- 进入“我的进度”时后台读取项目列表；
- 用户主动点击“建立长期项目”时才创建；
- AI回答需要项目上下文时使用已存在项目，不自动创建。

错误处理：

- 401：面板内显示“登录后可同步长期计划”，页面指导继续可用；
- 404：提示“项目服务未加载，已切换为本地操作指导”，不得抛出到错误边界；
- 409：刷新项目版本并提示用户重新采用计划；
- 503/网络错误：保留当前指导和本地步骤，允许重试；
- 所有事件处理函数必须捕获异步错误，不允许 `void promise` 的拒绝进入 Next.js开发错误遮罩。

## 8. 视觉与布局

延续当前蓝色业务中台风格，但把面板从“大块空白聊天抽屉”改为紧凑操作卡：

- 桌面宽度约 380–420px；
- 顶部显示页面和步骤，不重复大段品牌文案；
- 主体以步骤卡、检查项和完成标准为主；
- 当前步骤使用蓝色强调，已完成使用绿色，未开始使用灰色；
- 主按钮固定在底部；
- 控件高亮使用蓝色脉冲描边，不使用全屏黑色蒙层；
- 小屏幕改为底部抽屉，保留页面上半部分可见。

面板展开后允许遮盖非关键留白，但“定位操作”会确保目标控件滚动到未被面板遮挡的位置。

## 9. 与现有教程的关系

- `TutorialProvider` 继续负责完整模块教程和演示样例。
- 操作教练负责日常、随页面变化的短步骤指导。
- 两者共享场景数据和控件锚点。
- 当完整教程正在运行时，操作教练自动收起，避免两个引导层同时出现。
- 退出完整教程后，操作教练恢复到当前页面对应步骤。

## 10. 验收标准

### 基础使用

- 未登录、无项目时，视频/GEO页面仍能立即显示操作指导。
- 打开悬浮框不会调用创建项目接口。
- 从视频子页切换到另一视频子页，标题、步骤和控件定位同步更新。
- 从视频切换到 GEO，助理和指导内容正确切换。
- 身份定位、海报页不出现虚假的专属助理。

### 控件联动

- 每个支持页面至少有一个可以滚动并高亮的真实控件。
- 目标控件不存在时只显示可恢复提示。
- 指导面板不会代替用户触发生成、扣费或发布。

### 错误安全

- 项目接口返回 404/503 时不出现 Next.js错误遮罩。
- 未处理 Promise rejection 数量为零。
- 项目服务不可用时，确定性页面指导仍完整可用。

### 回归

- 现有完整教程、演示样例和算力阻断规则保持有效。
- 视频任务跨页轮询保持有效。
- GEO知识库、矩阵和文章工作流不改变生成协议。
- TypeScript检查、业务助理测试、教程测试和生产构建通过。

## 11. 非目标

- 不让模型直接读取或操控任意 DOM。
- 不自动点击生成、发布或付费按钮。
- 不为身份定位、海报或抖音截流新增助理。
- 不在本阶段增加语音对话或桌面级屏幕识别。
- 不重写现有视频/GEO业务页面。
