# 内容矩阵规划配置 A 版重设计

## 目标

将内容矩阵的规划配置改造成清晰的分层面板，降低用户理解成本，并彻底取消用户模型选择。矩阵生成只使用云端下发的文案模型，按云端优先级自动切换备用渠道。

## 选定方案

采用用户在三版可视化预案中选定的 A 版「分层配置面板」。页面按真实操作顺序组织为四层：

1. 目标优化模型：选择内容希望优先适配的 AI 引用策略，新项目默认豆包。
2. 发布平台：在策略区内多选平台，至少保留一个；系统自动加载对应平台知识库 Skill。
3. 企业知识库：按需引用企业官方信息。
4. 生成摘要：动态展示平台数量、预计主题数量与已启用策略。
5. 生成动作：整行主按钮，下方说明生成后仍可逐条调整。

## 界面结构

### 面板头部

- 左侧标题为「规划配置」。
- 右侧展示非交互状态「云端智能调度」。
- 不展示模型名称、模型下拉框或任何模型配置入口。
- 云端状态只解释系统行为，不允许用户改变路由。

### 三栏配置

- 删除面板顶部独立的平台胶囊行。
- 使用三块宽度一致的选择控件：目标优化模型、发布平台、企业知识库。
- “发布平台”占用原“平台爆款”的中间位置，并保留现有平台顺序与多选能力。
- 每次平台选择变化，都以平台到 `viralSkillId` 的注册映射同步 B 层 Skill；不再允许用户重复手选平台爆款 Skill。
- 旧项目载入时自动校准平台 Skill，清除与当前平台无关的历史手选项。
- 禁止取消最后一个平台。
- “目标优化模型”新项目默认 `model-doubao`；已保存模型选择不被覆盖。
- 每块同时展示类别名称与当前选择摘要，避免只显示「可选」。
- 发布平台显示已选平台数量；企业知识库显示已选 Skill 名称；目标优化模型显示当前策略。
- 桌面端优先一行三列，空间不足时自动换行；移动端纵向排列。

### 生成摘要与按钮

- 摘要文案动态计算为「准备生成 N 个平台的两周内容矩阵」。
- 预计主题数为 `平台数 × 14`。
- 摘要补充已启用的内容策略，不展示底层模型。
- 主按钮使用现有青色品牌色并横向占满可用区域。
- 生成期间禁用配置和按钮，按钮显示明确进度状态。

## 云端模型契约

- 前端删除 `provider` 状态、组件属性、项目自动保存字段和生成请求字段。
- 生成 API 忽略旧客户端传入的 `provider`，不得由客户端覆盖模型路由。
- 服务端只使用云端同步且 `source === "cloud"` 的文案模型候选。
- 候选按云端 `priority` 顺序尝试；网络错误、超时、非 2xx、无效 JSON 或空正文时自动尝试下一渠道。
- 不回退到本地环境变量或用户历史选择的模型。
- 没有云端候选时返回 `503 / CLOUD_MODEL_NOT_READY`。
- 所有候选均失败且没有生成任何有效平台内容时返回 `502 / CLOUD_MODEL_UNAVAILABLE`，不能把占位矩阵伪装成生成成功。
- 多平台并发生成可以分别触发渠道回退；项目持久化的兼容字段统一记录为 `cloud-managed`，不暴露或依赖单一模型。
- 沿用现有 `geo_matrix_gen` 单次计费，不因备用渠道切换重复扣费。

## 兼容与边界

- 保留 `MatrixProject.provider` 数据库字段，避免破坏旧项目与 FastAPI 数据结构，但新流程不再读取它做模型决策。
- `GenerateMatrixRequest.provider` 改为可选的弃用兼容字段或从前端类型中删除；服务端即使收到也忽略。
- 不修改深度优化文章创作、企业知识库搭建及其他 GEO 模块的界面。
- 不改变平台列表、矩阵数据结构、项目 CRUD、单元格编辑和现有 Skill 内容格式。

## 错误体验

- 云端配置未同步：提示「云端模型配置尚未同步，请稍后重试」。
- 云端渠道全部暂不可用：提示「云端生成服务繁忙，系统已尝试备用渠道，请稍后重试」。
- 已生成部分平台但个别平台失败：不静默显示占位内容；本阶段采用整批失败并允许用户重试，保证矩阵内容完整一致。
- 错误响应只包含渠道名称、模型名称、状态码和故障分类，不包含 API Key 或上游原始敏感响应。

## 验证标准

- 页面不存在 `GeoLlmProviderSelect`、模型名称或可点击模型入口。
- 生成请求和项目自动保存不发送 `provider`。
- 旧客户端发送任意 `provider` 不影响云端候选顺序。
- 首选渠道返回 5xx、网络错误或空内容时，测试确认请求备用渠道并成功生成。
- 所有渠道失败时返回稳定错误码，不保存占位矩阵。
- 平台数量、预计主题数量和策略摘要随选择实时更新。
- 企业知识库和内容策略下拉、生成按钮、矩阵结果及移动端布局通过回归验证。
