# 图片工作台专业创作台改版设计

日期：2026-07-27  
状态：待用户书面复核  
适用范围：图片工作台前端界面、用户可见状态文案和相关 UI 测试

## 1. 决策

图片工作台采用 Adobe Firefly 式专业创作台的信息架构，但不复制其品牌、素材或视觉资产。核心结构为：

1. 左侧固定生成参数面板。
2. 中央候选作品画布。
3. 画布底部固定提示词操作台。
4. 顶部保留紧凑的模式切换与任务入口。

现有图片生成、参考图、比例、计费和任务轮询协议保持不变。本阶段只重构产品体验，并补充能由现有生成能力支持的结果操作。

## 2. 设计目标

- 首屏即呈现完整工作流，避免页面式长表单与大面积装饰横幅。
- 作品是视觉中心，参数是辅助工具。
- 海报图创作和图片创作使用同一专业外壳，但保留各自内容结构、模板和参考图策略。
- 桌面端尽量不产生整页纵向滚动，参数面板内部独立滚动。
- 移动端保持完整能力，不把桌面三栏强行压缩。
- 用户界面不得暴露底层图片服务供应商、模型商品名、供应商控制台或供应商任务信息。

## 3. 视觉方向

### 3.1 场景

运营人员在办公室 24 至 27 英寸显示器上连续制作海报和社媒图片，需要长时间查看参数与多个候选结果。界面采用明亮、低刺激的专业工作室主题。

### 3.2 视觉语言

- 主背景：带轻微冷色的浅灰工作台。
- 参数面板与提示词操作台：暖白色。
- 正文：近黑墨色，不使用纯黑。
- 唯一高强调色：中台现有蓝色体系，用于选中态和生成按钮。
- 不使用紫红渐变 Hero、渐变文字、装饰性玻璃效果或嵌套卡片。
- 圆角收敛到 8 至 14 像素；阴影仅用于提示词操作台和生成结果。
- 标题层级紧凑，避免大标题占据创作空间。

## 4. 页面信息架构

### 4.1 顶部工具栏

从左到右：

- 页面名称“图片工作台”。
- 服务状态只显示业务化状态，例如“创作服务可用”，不显示供应商名称。
- 任务记录入口。
- 使用指南入口。

第二行是模式栏：

- 海报图创作。
- 图片创作。
- 当前单次生成积分。

模式切换保留两个板块各自的草稿、参考图、比例和最后一次结果。

### 4.2 左侧生成参数面板

宽度约 300 至 320 像素，按业务顺序分组，不再用大卡片包裹每个区域。

海报图创作：

1. 海报模板。
2. 海报用途、主标题、辅助文案。
3. 视觉方向。
4. 主体图与风格图两个固定参考槽。
5. 比例、横竖方向、清晰度。

图片创作：

1. 创作模板。
2. 补充要求。
3. 最多四张可排序参考图。
4. 有参考图时显示主体保持、参考风格、综合重绘。
5. 比例、横竖方向、清晰度。

### 4.3 中央候选作品画布

- 顶部显示候选数量、适应画布和并排比较。
- 空状态使用低干扰说明，不重复介绍技术模型。
- 生成中显示两个与目标比例一致的骨架画框，并显示业务阶段：
  - 正在准备创作任务。
  - 正在生成候选图。
  - 正在整理生成结果。
- 成功时并排显示两张候选图，使用完整包含方式，不裁切。
- 单张失败时保留成功结果并显示轻量提醒。
- 全部失败时显示可重试错误区，不清空用户输入。

每张结果提供：

- 下载。
- 设为参考图。
- 使用相同设置再次生成。

“设为参考图”遵循当前模式规则：海报要求用户选择主体图或风格图；图片创作追加到参考图队列，达到四张时提示先移除。

### 4.4 底部提示词操作台

- 固定在画布底部，始终是页面主操作。
- 海报模式用于补充画面创意描述，左侧结构化内容继续控制文字信息。
- 图片模式承载主要画面描述。
- 显示当前会使用的参考图数量和输出规格。
- 生成按钮明确显示“生成 2 张”和本次积分。
- 生成期间按钮变为阶段状态，不允许重复扣费提交。

## 5. 移动端

宽度小于 768 像素时：

- 顶部工具栏简化为标题、模式切换和任务入口。
- 画布位于参数之前，让用户优先看到结果。
- 参数面板改为页面内可展开的“创作设置”，不使用阻断式模态框。
- 提示词操作台保持在生成结果下方，不遮挡表单与全局业务助理。
- 比例选择保持四列；横竖方向和清晰度保持两列。

## 6. 供应商保密边界

底层供应商只存在于服务端配置、客户端封装和内部运维文档中。以下内容不得出现在浏览器可见区域或返回给浏览器的安全错误中：

- 供应商名称。
- 供应商模型商品名。
- 供应商 API 地址。
- 供应商任务 ID 的含义说明。
- 引导用户前往供应商控制台的文案。

前端统一使用：

- 图片生成引擎。
- 创作服务。
- 图片任务。
- 候选图生成。

服务端必须把供应商异常转换为产品级错误，例如：

- 创作服务暂时繁忙，请稍后重试。
- 参考图处理失败，请更换图片后重试。
- 候选图生成失败，本次未获得可用结果。

开发日志和内部诊断仍可记录供应商级错误，但浏览器响应不得原样透传。

## 7. 数据与技术边界

- 沿用 `/api/image-workbench/generate` 与 `/api/image-workbench/status`。
- 沿用 `poster_image` 与 `image_creation` 两个计费场景。
- 沿用固定生成两张候选图、文生图与图生图自动路由。
- 不新增环境变量。
- 不改云端计费价格。
- 不新增独立图片编辑器、局部重绘、扩图或超分辨率接口。
- 任务记录优先复用现有任务结果状态；若没有可靠持久化，本阶段入口只展示当前会话记录，不伪造跨设备历史。

## 8. 组件边界

- `ImageWorkbenchShell`：专业工作台布局和响应式结构。
- `ImageWorkbenchToolbar`：标题、模式、积分和任务入口。
- `ImageWorkbenchInspector`：模式对应的参数分组容器。
- `PosterCreationPanel`：海报业务字段。
- `ImageCreationPanel`：通用图片业务字段。
- `ImagePromptComposer`：底部提示词与生成主操作。
- `ImageResultCanvas`：空、生成、部分成功、成功和失败状态。
- `ImageResultActions`：下载、设为参考、再次生成。

业务状态与生成 API 仍由工作台上层协调，展示组件不直接决定计费场景或服务端端点。

## 9. 验收标准

- 图片工作台不再出现紫红渐变 Hero。
- 1440×900 桌面视口内同时可见模式栏、关键设置、结果画布和生成按钮。
- 海报与图片模式切换后各自草稿和结果不丢失。
- 四组比例和横竖方向均可选择。
- 海报两个参考槽和图片最多四张参考图规则保持有效。
- 两张结果均提供下载、设为参考和再次生成。
- 页面、加载状态、空状态、安全错误和帮助文案中不存在供应商名称或模型商品名。
- 全部前端相关测试、Python 图片管线测试和 TypeScript 类型检查通过。
- Playwright 验收桌面与移动布局，页面无运行时错误。

## 10. 不在本阶段

- 更换底层图片服务供应商。
- 新增第三种图片创作模式。
- 新增画布内像素级编辑能力。
- 新增跨设备作品资产库。
- 修改积分价格或退款策略。
