# 企业知识库云端模型路由设计

## 目标

企业知识库 Skill 生成不再向用户展示或接受模型选择。服务端只使用云端同步的文案模型，并按云端 `priority` 顺序自动故障切换。

## 契约

- 前端不展示“大模型”选择器，也不发送 `provider`。
- 服务端忽略旧客户端携带的 `provider`，避免客户端覆盖云端策略。
- 仅使用 `source === "cloud"` 的文案模型候选；不回退到本地环境变量模型。
- 网络异常、超时、上游非 2xx、空响应或无有效正文时继续尝试下一云端渠道。
- 全部渠道失败时返回 `502 / CLOUD_MODEL_UNAVAILABLE`；尚未同步任何云端模型时返回 `503 / CLOUD_MODEL_NOT_READY`。
- 成功生成的 Skill 记录实际成功的云端渠道与模型，保持现有本地知识库数据结构兼容。
- 沿用现有 `geo_skill_gen` 单次计费，不因渠道切换重复扣费。

## 边界

本次只修改企业知识库生成面板与对应 API；其他 GEO、文案和视频创作模块的模型路由不变。
