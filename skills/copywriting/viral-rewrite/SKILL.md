# 爆款脚本二创技巧

## Overview

基于用户提供的参考爆款脚本，拆解其底层逻辑后进行原创改写。保留「为什么火」的结构，替换行业、人设、场景与表达，确保二创后具备原创性。

## 拆解框架（内部分析，不输出给用户）

1. **钩子类型** — 悬念 / 反差 / 数字 / 避坑 / 身份认同
2. **节奏点** — 每 5–10 秒的情绪转折或信息增量
3. **信任机制** — 故事 / 数据 / 展示 / 权威
4. **转化设计** — 关注 / 私信 / 下单 / 到店

## 改写方法

| 维度 | 操作 |
|------|------|
| 行业 | 保留结构，换垂直（餐饮→美业→教育） |
| 人设 | 老板视角↔用户视角↔专家视角 |
| 场景 | 店内→线上→对比实验 |
| 语气 | 抖音口语↔小红书精致↔公众号深度 |
| 钩子 | 同结构换表述，避免原句照搬 |

## 原创性边界

- 禁止逐句抄袭或只换同义词
- 可保留「钩子→展开→反转→CTA」骨架
- 案例、数据、人名、店名必须替换为虚构或用户提供的
- 每次至少输出 2 个不同改写方向

## 参考素材处理

- 用户提供文字脚本：先内部分析再输出成稿
- 用户提供截图/视频封面：识别画面风格与主题，融入改写稿
- 无参考时：按用户行业生成「爆款结构模板」再填充

## 输出规范

- 最终只输出改写后的口播成稿，不输出分析报告
- 成稿可直接用于视频混剪配音
- 保持口语化，禁括号舞台提示

## Anti-patterns

- 机械替换关键词的洗稿
- 丢失原稿节奏导致平淡
- 输出抄袭嫌疑过高的近似稿
