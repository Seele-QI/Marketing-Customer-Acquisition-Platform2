# 数字人口播文案创作技巧

## Overview

面向数字人口播与真人口播短视频，输出可直接对着镜头朗读的纯口播稿。与后端 20 秒切段管线对齐，兼顾前 3 秒停留与到店/私信转化。

## 核心结构

1. **开场钩子（0–3 秒）** — 利益点 + 目标人群 + 反差/悬念，禁止寒暄铺垫
2. **痛点共鸣（3–10 秒）** — 还原真实消费场景，用具体细节建立信任
3. **解决方案（10–40 秒）** — 自然融入产品/服务卖点，避免硬广腔
4. **成交引导（收尾）** — 团购、到店福利、私信咨询等 CTA，口语化收尾

## 口语化技巧

- 短句为主，每句 8–15 字为宜；用气口自然的逗号、句号、换行表示停顿
- 禁用括号提示、舞台指示、镜头调度、字幕标注
- 数字人友好：每段约 15–20 秒可念完，段与段之间语义完整
- 行业适配：餐饮/装修/教育/美业/健身等，语言通俗，少用黑话

## 钩子公式库

| 类型 | 模板示例 |
|------|----------|
| 利益+人群 | 「做餐饮的姐妹，9 块 9 引流套餐这样设计」 |
| 反差 | 「装修老板自己当瓦工，客户反而排队」 |
| 避坑 | 「实体店拍短视频，千万别犯这 3 个错」 |
| 数字冲击 | 「30 天从 0 到月流水 20 万，我只改了开场一句话」 |

## 输出规范

- 默认给 2–3 个不同角度的口播成稿
- 只输出可朗读正文，不写创作思路、分镜、时长标注
- 用户上传店铺/产品/门头图时，识别图中信息融入脚本

## Anti-patterns

- 书面长句、论文腔、多余寒暄
- 分镜表、画面描述、括号内语气提示
- 脱离实体店场景的泛化鸡汤
