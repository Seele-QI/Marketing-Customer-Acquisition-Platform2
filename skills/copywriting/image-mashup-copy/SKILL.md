# 图文视频混剪文案创作技巧

## Overview

为「图片轮播 + 配音」或「多段视频素材混剪」两类成片写旁白稿。文案需与画面段落一一对应，便于字幕烧录与 BGM 卡点。

## 图文视频模式（图片轮播）

- **分段旁白**：每张图/每组图对应 3–8 秒旁白，一句一画面
- **开场定调**：第一张图配合强钩子句，说明「这条视频讲什么」
- **字幕友好**：每句 ≤ 20 字，避免从句套从句
- **收尾 CTA**：最后 1–2 句引导关注、私信、到店

结构示例：
```
[图1 门头] 钩子句 — 3 秒
[图2 环境] 场景代入 — 5 秒
[图3 产品] 核心卖点 — 6 秒
[图4 效果] 用户证言/对比 — 5 秒
[图5 福利] 行动号召 — 4 秒
```

## 视频混剪模式（多素材拼接）

- **转场衔接词**：段与段之间用「接下来」「更关键的是」「你以为完了？」等口语桥接
- **节奏变化**：高潮段用短句加速，信任段用稍长句稳节奏
- **BGM 卡点意识**：在情绪转折点留半拍停顿（用句号/换行），便于后期配乐
- **统一叙事线**：多素材不能各说各话，需一条主线贯穿

## 写作原则

- 按素材顺序写，标注可选的「对应画面提示」（仅内部构思，最终稿去掉标注只留口播正文）
- 混剪场景强调「信息密度」：每秒传递一个有效信息点
- 朋友圈/社群裂变话术可融入，但输出仍以口播旁白为主

## 输出规范

- 给完整旁白成稿，可按段落换行
- 每次 2 个版本：沉稳信任版 / 快节奏种草版
- 用户上传活动海报、产品组图时，识别视觉信息写入旁白

## Anti-patterns

- 与画面无关的抽象议论
- 单段过长导致字幕溢出
- 混剪各段主题跳跃无衔接
