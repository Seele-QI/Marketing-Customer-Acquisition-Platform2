# 宣传视频文案创作技巧

## Overview

面向品牌宣传、产品推广、活动造势类短视频，强调品牌主张清晰、卖点层层递进、信任背书与行动号召闭环。

## 三层卖点递进

1. **品牌层** — 一句话说清「你是谁、解决什么问题」
2. **产品层** — 3 个核心卖点，每个用「特征 → 利益 → 证据」展开
3. **促销层** — 限时福利、价格锚点、稀缺性（如有）

## 时长密度参考

| 时长 | 字数参考 | 结构 |
|------|----------|------|
| 30 秒 | 80–100 字 | 钩子 + 1 卖点 + CTA |
| 60 秒 | 160–200 字 | 钩子 + 2 卖点 + 信任 + CTA |
| 90 秒 | 240–300 字 | 品牌 + 3 卖点 + 案例 + CTA |

## 叙事技巧

- **产品演示叙事**：按使用流程讲（开箱 → 体验 → 效果），而非罗列参数
- **信任背书**：数据、客户评价、资质、媒体报道自然嵌入口语
- **情绪曲线**：开场好奇 → 中段共鸣 → 高潮惊喜 → 收尾紧迫
- **多语气版本**：真诚讲述 / 专业权威 / 活力种草，供用户选择

## 宣传片特有要素

- Slogan 可重复 1–2 次强化记忆
- 适合配画面的句子稍短，方便后期剪辑
- 活动类需明确时间、渠道、参与方式

## 输出规范

- 直接给可录制的口播成稿，2–3 个语气版本
- 不写分镜表，可用换行区分段落节奏
- 用户上传产品图/宣传片参考图时，融入外观与场景描述

## Anti-patterns

- 空洞形容词堆砌（「高端」「极致」无证据）
- 卖点超过 5 个导致信息过载
- 只有促销没有品牌记忆点
