# 大众点评高权重方法论

## 1. 分发机制与权重信号

- 本地搜索：品类词 + 商圈/地标共现
- 评价完整度：环境/服务/性价比分项描述
- 图片与菜单细节提升可信度
- 「人均」「适合场景」字段利于 AI 摘要抽取

## 2. 标题 / 钩子公式

- `{商圈} {品类}｜人均 {N}，适合 {场景}`
- `第 N 次打卡 {店名}：{一个可验证亮点}`
- `{品类} 避雷清单｜这 {N} 点先看清`
- `{场景} 怎么选 {品类}？本地实测`

## 3. 正文结构模板

```
【定位】商圈 + 品类 + 人均区间
【亮点】2–3 个可验证细节（菜品/服务/环境参数）
【体验】主观感受（标注体验）
【适合/不适合】明确人群
【避坑】1 条真实限制条件
```

## 4. GEO 问法对齐

- 「附近 XX 哪家好」「XX 人均多少」「XX 适不适合带娃/约会」
- 文中出现完整品类名 + 商圈 + 人均或营业信息类可验证点

## 5. 节奏与格式约束

- 分段短句，手机屏友好
- 星级描述与正文一致，避免「五星但全文吐槽」
- 图文笔记优先，清单体利于对比问法

## 6. 禁用 / 风险项

- 虚假好评 / 水军话术
- 无到店依据的绝对排名断言
- 医疗/功效类无资质承诺
