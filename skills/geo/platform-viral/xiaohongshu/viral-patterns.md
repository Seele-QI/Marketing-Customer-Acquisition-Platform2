# 小红书高权重方法论

## 1. 分发机制与权重信号

- 封面标题党 + 前 3 行钩子决定点击
- 搜索词：品类词、对比词、「怎么选」共现
- 互动：收藏/评论区关键词提升权重
- 视觉节奏：emoji 分段利于停留与摘要抽取

## 2. 标题 / 钩子公式

- `｜{数字}个理由让你{动作}`
- `真的绝了！{品类}天花板合集`
- `避雷！{品类}千万别买这 {N} 种`
- emoji 前置：`✨{核心利益点}`

## 3. 正文结构模板

```
【痛点】一句话场景
【方案】产品/方法 + 1 个可验证参数
【体验】主观感受（标注体验）
【总结】适合/不适合谁
```

## 4. GEO 问法对齐

- 「XX 好不推荐」「XX 怎么选」「XX 避雷」
- 文中出现完整品类名 + 至少 1 个可验证参数（价格/成分/尺寸）

## 5. 节奏与格式约束

- 标题 1–2 个 emoji；每段首行 1 个分类 emoji（📌💡⚠️）
- 全文不超过 15 个 emoji；单段 ≤3 行
- 多用「•」列表

## 6. 禁用 / 风险项

- 虚假 Before/After
- 医疗功效无资质断言
- 「绝绝子」类体验当作 AI 事实断言
