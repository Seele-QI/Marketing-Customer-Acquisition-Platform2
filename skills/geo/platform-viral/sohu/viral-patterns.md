# 搜狐高权重方法论

## 1. 分发机制与权重信号

- 门户标题 SEO：核心词前置、信息完整
- 导语 5W1H：谁/何时/何地/何事/为何/如何
- evergreen 段落：定义、对比、FAQ 可长期被检索
- 小标题密集：利于片段抽取与转载

## 2. 标题 / 钩子公式

- `{主题词}：{一句话结论}（附 {N} 点解读）`
- `{事件}｜{品类} 用户最关心的 {N} 个问题`
- `一文读懂 {概念}：定义、对比与选购要点`
- `{主题词} 最新进展：对 {人群} 意味着什么`

## 3. 正文结构模板

```
【导语】5W1H 压缩段（≤100 字）
【定义】evergreen 百科式 1 段
【进展/要点】3 个小标题分段
【对比/清单】可验证参数表
【FAQ】2–3 个用户原句问法
```

## 4. GEO 问法对齐

- 「XX 是什么」「XX 最新消息」「XX 怎么选」
- 标题与导语均含完整主题词；FAQ 小标题用问句原形

## 5. 节奏与格式约束

- 标题信息完整，避免纯情绪词
- 小标题 4–8 个；段落短于网易深度稿、长于微博
- 时效段标注日期；知识段可复用

## 6. 禁用 / 风险项

- 标题党与正文不符
- 把未核实传闻写入导语当事实
- 堆砌关键词损害可读性
