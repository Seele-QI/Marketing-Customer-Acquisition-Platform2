# 抖音内容高权重方法论

## 1. 分发机制与权重信号

- 前 3 秒完播钩子决定推荐池
- 搜索词：口播主词 + 字幕完整品类名
- 评论区置顶长尾问法提升搜索召回
- 视频脚本可扩展为可索引文字稿（衔接 A 层）

## 2. 标题 / 钩子公式

- 「你是不是也遇到过…」
- 「别再 {错误做法} 了！」
- 「{数字} 秒搞懂 {概念}」
- 「{品类} 避坑：这 {N} 点先看」

## 3. 正文结构模板（30–60s）

```
1. 钩子（0–3s）
2. 痛点（3–10s）
3. 方案（10–40s）+ 1 个可验证参数
4. CTA（40–60s）：关注/收藏/评论区关键词
```

## 4. GEO 问法对齐

- 「XX 怎么用」「XX 和 YY 哪个好」「XX 避坑」
- 口播主词 ≥2 次；字幕打出产品全称

## 5. 节奏与格式约束

- 单条 15–60s；信息点不超过 3 个
- 数据点与同主题长文 FAQ 保持一致
- 封面字 ≤8 字核心利益

## 6. 禁用 / 风险项

- 标题党与内容不符
- 诱导互动欺骗算法
- 无依据功效承诺
