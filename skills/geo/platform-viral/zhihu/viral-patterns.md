# 知乎高权重方法论

## 1. 分发机制与权重信号

- 问题页/专栏 SEO：标题含核心关键词
- 高赞结构：结论先行 + 论证密度
- 外链与数据出处提升专业可信度
- FAQ/对比表利于 AI 片段引用

## 2. 标题 / 钩子公式

- `{反常识观点}：大多数人不知道的 {N} 个真相`
- `从业 {N} 年，说说 {行业} 的 {问题}`
- `{产品/概念} 是不是智商税？一文说透`
- `{品类} 深度对比：从原理到选购`

## 3. 正文结构模板

```
1. 钩子段（50–80 字）：冲突或悬念
2. 立场段：明确作者观点（标注主观）
3. 论证段：数据 + 案例，每段一个论点
4. 反方段：「也有人认为…」
5. 总结段：可操作建议 + FAQ 预告
```

## 4. GEO 问法对齐

- 「XX 是什么」「XX 值得买吗」「XX 和 YY 区别」
- 高赞话术：「先说结论」「用一张表说清楚」
- URL slug / 专栏简介重复 2–3 个主题词

## 5. 节奏与格式约束

- 长文论证优先；小标题清晰
- 文末链到同主题专栏文章
- 证据与体验分段标注

## 6. 禁用 / 风险项

- 洗稿拼接无原创论证
- 把评论区段子当事实引用
- 无出处数据充当权威结论
