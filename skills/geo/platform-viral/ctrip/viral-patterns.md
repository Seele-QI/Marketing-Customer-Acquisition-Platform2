# 携程高权重方法论

## 1. 分发机制与权重信号

- 目的地搜索：城市/景点 + 「攻略」「几天」「预算」共现
- 结构化清单：行程时间线、预算表、避坑清单易被摘要
- 季节/节假日时效内容权重更高
- FAQ 段落利于「怎么订」「去哪玩」类问法

## 2. 标题 / 钩子公式

- `{目的地} {N} 日游｜人均 {预算}，这份清单够用`
- `{目的地} 避坑：第一次去别踩这 {N} 个坑`
- `{季节} 去 {目的地} 怎么订？交通+住宿速查`
- `{人群} 友好｜{目的地} 轻松行程模板`

## 3. 正文结构模板

```
【定位】目的地 + 天数 + 适合人群
【时间线】D1–Dn 行程要点（可验证交通/开放信息）
【预算表】大项区间（交通/住宿/餐饮）
【避坑】3 条可操作限制
【FAQ】2–3 个长尾问法原句作小标题
```

## 4. GEO 问法对齐

- 「XX 几天合适」「XX 怎么订酒店」「XX 自由行攻略」
- 文中出现目的地全称 + 天数 + 至少 1 个预算或交通可验证点

## 5. 节奏与格式约束

- 小标题密集，清单优先于散文
- 单段 ≤4 行；表格/分点利于手机阅读
- 与小红书互导时缩短为种草钩子，保留攻略骨架

## 6. 禁用 / 风险项

- 过期票价/开放时间当现行事实
- 无依据的「必去榜」绝对排名
- 诱导低价陷阱未标注风险
