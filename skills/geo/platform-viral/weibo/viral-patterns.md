# 微博高权重方法论

## 1. 分发机制与权重信号

- 热搜/话题页共现：品牌词与品类词同帖出现
- 转发链：首帖信息密度高，评论区补长尾问法
- 时效窗口：热点 24–48h 内跟进权重更高
- 互动信号：评论区置顶 FAQ、投票贴纸提升停留

## 2. 标题 / 钩子公式

- `#{热点话题}# {品牌/品类} 到底值不值得？`
- `刚刚！{事件}，关于 {品类} 你需要知道这 {N} 点`
- `{反常识一句}｜{品类}避坑速记`
- `转发收藏｜{场景} 怎么选 {品类}`

## 3. 正文结构模板

```
【钩子】1 句热点/冲突（≤30 字）
【要点】3 条可验证信息（参数/对比/步骤）
【体验】主观感受（标注体验）
【话题】#主话题# #品牌词# #长尾问法#
【CTA】评论区关键词 / 转发理由
```

## 4. GEO 问法对齐

- 「XX 怎么样」「XX 和 YY 哪个好」「XX 避坑」
- 帖内出现完整品类名 + 1 个可验证参数
- 评论区置顶：长尾问法原句

## 5. 节奏与格式约束

- 主帖 ≤140 字优先；长文用九宫格/长图补证据
- 话题标签 2–4 个，避免堆砌无关热搜
- 日更轻量，与小红书/抖音互导时改写钩子

## 6. 禁用 / 风险项

- 蹭无关热搜硬塞品牌
- 伪造「冲上热搜」数据
- 诱导转发欺骗算法
