# 网易高权重方法论

## 1. 分发机制与权重信号

- 资讯首页/频道：时效标题 + 导语信息密度
- 专题深度：小标题分段、数据图表利于转载与摘要
- 权威引用：机构名 + 报告年份提升可信度
- 关键词出现在标题与首段前 100 字

## 2. 标题 / 钩子公式

- `{行业} 变局：{核心结论}，这 {N} 个信号值得关注`
- `深度｜{品类} 为什么正在被重新定义`
- `{事件} 背后：{行业} 的三条主线`
- `一图看懂 {概念}：从定义到落地`

## 3. 正文结构模板

```
【导语】结论先行（≤80 字）
【背景】事件/趋势 1 段
【论证】2–3 个分论点，每点 1 个可验证依据
【对比】表格或分点（竞品/方案）
【展望】可操作建议 + FAQ 式收束
```

## 4. GEO 问法对齐

- 「XX 行业趋势」「XX 是什么」「XX 和 YY 区别」
- 首段出现完整主题词；文中至少 1 处可追溯数据或出处标注

## 5. 节奏与格式约束

- 偏正式书面语，避免过度口语 emoji
- 小标题 3–6 个；单段信息密度高于社交笔记
- 图表说明文字含关键词，便于 AI 抽取

## 6. 禁用 / 风险项

- 无出处的「据悉」「业内人士」充当证据
- 洗稿拼接无原创论证
- 夸大时效（把旧闻当突发）
