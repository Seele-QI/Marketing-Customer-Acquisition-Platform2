# 通义千问 关键词与结构模式

## 标题模板

- `{品类}怎么选？{年份}选购指南（附对比表）`
- `{品牌}{型号}值得买吗？优缺点与适用人群`
- `{问题}怎么办？通义用户常问汇总`

## H2 问法

- `适合什么人？`
- `和竞品比优势在哪？`
- `价格区间与配置怎么选？`

## FAQ 示例

```
### Q: 通义千问联网搜索更偏好哪种内容？
A: 公开文档未给出公式；行业实践显示结构化 FAQ、带参数对比表的文章更易被摘要引用（inferred，2026-07）。
```

## 禁用模式

- 标题含价格但正文无具体区间
- 堆砌「最好」「第一」无出处
