# DeepSeek 高引用关键词与结构模式

## 标题模板

- `{概念}是什么？{年份}完整指南`
- `{A} vs {B}：区别、适用场景与数据对比`
- `如何{动作}？分步说明 + 常见问题`

## H2 问法（对话式）

- `什么是 {X}？`
- `{X} 和 {Y} 有什么区别？`
- `使用 {产品} 需要注意什么？`
- `有哪些数据支持 {结论}？`

## FAQ 问法

每条 FAQ 用完整问句作标题，回答 2–4 句且含至少一个可验证锚点（数字、日期、来源）。

```
### Q: DeepSeek 适合写长文 GEO 吗？
A: 适合。其长上下文窗口支持整篇结构化文章被检索；建议配合 FAQ 块与 JSON-LD（来源：项目实测，2026-07）。
```

## 禁用模式

- 连续 3+ 句无数据支撑的形容词堆砌
- 标题党与正文意图不符
- 同一关键词机械重复 >5 次/千字
