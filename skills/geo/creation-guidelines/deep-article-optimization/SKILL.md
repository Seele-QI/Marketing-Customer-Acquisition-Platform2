# 深度优化文章创作准则（GEO）

本准则用于把平台内容写成 **可检索、可引用、证据可验证** 的 GEO 文章（纯文本、目标 900–1100 字）。

---

## 硬规则：先检索再动笔

- 在写任何“事实性结论 / 数据 / 行业结论”前，先完成最小检索（至少 2 个平台 + 1 组可引用来源）。
- 若用户要求“不用查资料”，必须降级为：
  - 只输出“可验证的写作框架 + 检索清单 + 风险提示”
  - 或明确标注为“假设/经验性观点”，不得伪造数据与来源。

## 硬规则：格式与篇幅（产品落地）

- **纯文本**：禁止 Markdown 标记、emoji、装饰符号、JSON-LD 代码块
- **目标篇幅**：全文（含文末标签行）控制在 **900–1100** 个非空白字符
- **硬上限**：任何成功成稿不得超过 **1200** 个非空白字符
- **完整性**：禁止依靠字符级截断压缩文章；异常成稿最多进行一次结构化重写
- **标签**：文末固定一行 `标签：#a #b #c`（3–5 个）

## 写作清单（四维）

### 1) 语义清晰度

- 概念先定义：同义词、边界、与相邻概念的区分
- 小节标题对齐用户意图与检索 query（纯文本标题，勿用井号）

### 2) 对话式设计

- 优先使用“用户会问什么”的问答结构，而不是堆砌术语
- 全文控制篇幅，1–2 条简短 FAQ 即可

### 3) 证据驱动

- 关键结论注明「需验证」或「经验性观点」，避免伪造不可访问链接
- 区分：事实 / 观点 / 经验 / 推测

### 4) 结构化 FAQ + 标签

- 文末 FAQ（可选 1–2 条）必须可验证、可引用
- **必须**输出文章标签行；**不要**附带 JSON-LD

## 四种文章结构（每篇只选一种）

### 1) 新手清单

- 适用：入门、步骤、怎么办、必做事项、教程
- 顺序：痛点与适用范围 → 3–5 个“做什么/为什么/怎么做”小节 → 执行顺序或避坑提醒 → FAQ

### 2) 对比问答

- 适用：哪个好、怎么选、A 与 B、区别、优缺点
- 顺序：比较范围 → 成本/能力/风险/场景问答 → 按条件给出选择建议

### 3) 避坑 FAQ

- 适用：坑、误区、风险、注意事项、常见问题
- 顺序：典型场景 → 3–5 个“表现/后果/规避方法”小节 → 检查清单 → FAQ

### 4) 真实案例分享

- 适用：经历、案例、复盘、经验分享、人群故事
- 顺序：案例背景与边界 → 问题/动作/结果与限制/可复制建议 → 适用与不适用条件
- 不能虚构第一人称经历、客户评价或第三方背书

## 多平台合规

所有文章先应用通用规则，再叠加目标平台规则。

- 通用：避免绝对化排名、无条件效果承诺、无来源数字、虚构经历、竞品攻击、站外导流和隐私泄露
- 高风险行业：财税、法律、医疗、健康、教育、投资等结论需说明适用条件、时间地域和核验渠道
- 小红书：真实体验、商业关系、种草效果和站外导流
- 抖音：虚假夸张宣传、恶意蹭热点、危险引导和变体规避词
- 微博：未经核实爆料、谣言式断言、攻击引战和话题垃圾营销
- 大众点评：虚构消费经历、利益相关评价、诱导好评和评分操纵
- 知乎：恶意营销导流、低质复制、伪造专业身份和无证据结论
- 携程：虚构入住/旅行体验、过时信息及无法核验的价格与排名
- 网易、搜狐：资讯事实、时间、来源、标题夸张和虚假新闻口吻

平台规则用于降低常见审核风险，不宣称覆盖平台全部动态词库。

## A+B+C 知识库组合工作流

深度优化文章创作页通过 **GeoSkillToolbar** 选择三轨知识库：

| 层级 | 含义 | 存储键 | 选择方式 |
|------|------|--------|----------|
| **A** | 大模型引用权重 | `geo-article-model-skill` | 单选 |
| **B** | 平台爆款逻辑 | `geo-article-viral-skills` | 多选 |
| **C** | 企业知识库 | `geo-article-enterprise-skill` | 单选（localStorage 生成） |

### 推荐流程

1. **选 A**：确定目标 AI 引擎（DeepSeek / 通义 / 豆包 / 抖音 AI 搜索）的引用权重策略 → 读 `skills/geo/model-weights/{platform}/`
2. **选 B**：确定资讯平台话术（知乎 / 小红书 / 贴吧 / 抖音内容）→ 读 `skills/geo/platform-viral/{platform}/`
3. **选 C**（可选）：加载企业知识库搭建页生成的 Skill → `localStorage` `geo-enterprise-skills-v1`
4. **检索**：`GeoResearchPanel` 按 B 选中平台拉参考
5. **起草**：A 的 checklist + weight-matrix + B 的 viral-patterns + C 的品牌实体/FAQ
6. **探测**：`POST /api/geo/ai-probe`
7. **输出**：纯文本文章 + FAQ（可选）+ 文末标签行；由生成校验保证成功成稿 ≤1200 字

> A 层权重为**策略参考，非官方公式**；B 层体验观点须与可验证事实分离。

---

## 伦理边界（必须遵守）

- 禁止洗稿/抄袭：不能把小红书/知乎等内容“拼接成稿”伪装为原创论证。
- 禁止对抗性 GEO：不得通过虚假数据、隐蔽文本、对抗性提示注入误导模型与读者。
