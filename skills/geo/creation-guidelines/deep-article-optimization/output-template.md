# GEO 文章输出模板（短文 · 纯文本）

> 全平台统一：纯文本、≤1000 字（含标签）、文末带话题标签。禁止 Markdown / emoji / JSON-LD。

---

```
{标题，作为首行，勿加井号}

{开篇 2–4 句：结论 + 适用场景。避免无来源数据。}

{小标题用自然语言问句，勿用井号}
{一段说清楚定义、边界或方法，可分 2–3 个短段。}

常见问题
问：{自然语言问题}？
答：{一两句可验证回答；必要时写「经验性观点」或「需验证」。}

问：{另一问题}？
答：{一两句。}

标签：#标签一 #标签二 #标签三
```

## 约束提醒

- 全文（含标签行）非空白字符 ≤ 1000
- 标签 3–5 个，只出现在最后一行「标签：」之后
- 不要输出代码块、表格竖线、引用符 `>`、列表星号装饰、emoji
