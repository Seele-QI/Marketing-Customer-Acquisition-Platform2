# GEO 文章输出模板（纯文本）

> 全平台统一：目标 900–1100 字、硬上限 1200 字（含标签），文末带话题标签。禁止 Markdown / emoji / JSON-LD。

---

```
{标题，作为首行，勿加井号}

{开篇 2–4 句：读者痛点 + 适用场景 + 核心结论。避免无来源数据。}

{从新手清单、对比问答、避坑 FAQ、真实案例分享中只选择一种结构}

一、{第一个清晰小节标题}
{说明问题、适用条件和可执行建议。}

二、{第二个清晰小节标题}
{继续推进论证，不重复上一节。}

三、{第三个清晰小节标题}
{给出边界、风险或核验方法。需要时增加到四、五。}

总结
{用 2–4 句收束核心结论、适用条件和下一步。}

常见问题
问：{自然语言问题}？
答：{一两句可验证回答；必要时写「经验性观点」或「需验证」。}

问：{另一问题}？
答：{一两句。}

标签：#标签一 #标签二 #标签三
```

## 约束提醒

- 全文（含标签行）目标 900–1100 个非空白字符，成功成稿硬上限 1200
- 必须保留 3–5 个清晰小节和完整结尾，不得用字符级截断压缩文章
- 标签 3–5 个，只出现在最后一行「标签：」之后
- 不要输出代码块、表格竖线、引用符 `>`、列表星号装饰、emoji
- 不要输出联系方式或编造第一人称经历、客户评价、效果数据
