# 跨平台叙事一致性

## 两周主题弧

```
W1: 认知建立 ──► 痛点共鸣 ──► 教程入门 ──► FAQ/对比预告
W2: 深度对比 ──► 案例证明 ──► 权威背书 ──► 转化 CTA
```

同一 `themeArc` 在各平台的表现：

| 平台 | W1 侧重 | W2 侧重 |
|------|---------|---------|
| 小红书 | 种草笔记、清单体 | 对比测评、购买建议 |
| 抖音 | 痛点短视频 | 案例口播、搜索词 FAQ |
| 知乎 | 概念长文 | 深度对比文、数据论证 |
| 微博 | 话题短帖 | 转发案例、话题收官 |
| 大众点评 | 体验笔记 | 深度体验复盘 |
| 携程 | 攻略入门 | 行程对比与预订指南 |
| 网易/搜狐 | 行业解读 | 权威数据与趋势 |

## 差异化原则

1. **同主题、不同格式**：知乎长文 vs 抖音 30s vs 小红书 9 图
2. **同数据、不同呈现**：表格（知乎）→ 口播数字（抖音）→ 信息图（小红书）
3. **发布时间错开**：核心内容间隔 24–48h，避免平台算法互斥
4. **互导但不重复**：文末/简介引导至其他平台深度版，禁止全文搬运

## themeArc 命名

- 使用 4–12 字主题短语，如「夏季防晒选购」「门店私域获客」
- 全平台 14 天内同一弧不超过 2 个并行（避免用户认知分散）
