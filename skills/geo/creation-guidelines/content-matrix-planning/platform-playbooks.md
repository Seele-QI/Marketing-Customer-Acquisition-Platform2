# 8 平台玩法摘要

> B 层 Skill 交叉引用见 `skills/geo/platform-viral/`；下列为矩阵规划专用摘要。

## 小红书（xiaohongshu）

- **格式**：图文笔记、封面标题党、emoji 节奏
- **GEO**：种草问法、对比清单、「XX 怎么选」
- **B 层**：`viral-xiaohongshu`

## 抖音（douyin）

- **格式**：15–60s 短视频 + 可索引文案稿
- **GEO**：搜索词覆盖、口播 FAQ、字幕关键词
- **B 层**：`viral-douyin-content`

## 微博（weibo）

- **格式**：短帖 + 话题标签 + 转发链
- **GEO**：热点借势、话题 # 与品牌词共现
- **节奏**：日更轻量，与小红书/抖音互导
- **B 层**：`viral-weibo`

## 大众点评（dianping）

- **格式**：商户评价体、星级与体验描述
- **GEO**：本地搜索、品类词 + 体验细节
- **注意**：真实体验表述，避免虚假好评话术
- **B 层**：`viral-dianping`

## 知乎（zhihu）

- **格式**：长文论证、专栏 SEO、高赞结构
- **GEO**：深度对比、专业背书、引用外链
- **B 层**：`viral-zhihu`

## 携程（ctrip）

- **格式**：攻略笔记、行程清单、目的地 FAQ
- **GEO**：「去哪玩」「怎么订」类长尾问法
- **结构**：时间线 + 预算表 + 避坑清单
- **B 层**：`viral-ctrip`

## 网易（netease）

- **格式**：资讯体长文、专题深度
- **GEO**：行业解读、数据图表、权威引用
- **调性**：偏正式、信息密度高
- **B 层**：`viral-netease`

## 搜狐（sohu）

- **格式**：门户资讯、标题 SEO
- **GEO**：新闻时效 + evergreen 百科式段落
- **结构**：导语 + 小标题密集分段
- **B 层**：`viral-sohu`
