# 两周 Sprint 模板（14 天内容矩阵）

## 表格字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `date` | ISO date | 计划发布日（从当天起算连续 14 天） |
| `week` | 1 \| 2 | 第一周立题 / 第二周深化 |
| `themeArc` | string | 跨平台关联主题弧（同弧用相同标识文案） |
| `title` | string | 该平台原生标题（≤30 字为宜） |
| `contentDirection` | string | 创作方向：角度、要点、CTA（抽屉详情展示） |
| `format` | string | 图文 / 短视频 / 笔记 / 攻略 / 长文 / 点评 等 |
| `geoIntent` | string | 对比 / 教程 / FAQ / 种草 / 榜单 / 案例 |
| `platformNative` | string | 该平台特有要点（钩子、标签、互动设计） |

## 周节奏

### 第一周（W1）— 立题

- D1–D2：核心概念定义 + 用户痛点共鸣
- D3–D4：教程/How-to 建立专业感
- D5：FAQ 或对比入门
- D6–D7：轻量种草或案例预告

### 第二周（W2）— 深化与转化

- D8–D9：深度对比 / 选购指南
- D10–D11：案例拆解 / 用户证言
- D12：权威背书（数据、第三方引用）
- D13–D14：转化 CTA + 系列预告

## 格数契约

- 每平台 **恰好 14 格**（一日一格，D1–D14）
- `week`：D1–D7 = 1，D8–D14 = 2
- 热点跟进可在对应日的 `contentDirection` 标注「反应式」角度
